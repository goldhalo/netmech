build: -Werror / /WX 只约束库与 example，test/ 不再因告警中断

策略调整（按评审意见）：
- 库代码上生产、example 会被使用者照抄 → 这两处必须零告警；
- test/ 的价值是"用例能过"，第三方头在新版本里频繁引入弃用警告
  （OpenSSL 4.1 弃用 X509_check_host、4.x 把一批 getter 改成返回 const），
  为这些反复改测试只是拿精力跟工具链赛跑。

实现：
- 把 /WX、-Werror 从 netmech_compile_options（PUBLIC interface，会传给
  测试/示例/下游使用者）挪到按目标添加：netmech 与 netmech_echo /
  netmech_udp / serial_check
- NETMECH_WARNINGS_AS_ERRORS 的语义与文档随之收窄

同时（上一个提交遗留的）测试侧兼容 OpenSSL 4.x：
- test_tls_e2e.cpp 构造自签证书改成"新建 ASN1_INTEGER/ASN1_TIME/X509_NAME
  → set 进去"，不再用 X509_get_serialNumber / X509_getm_* / X509_get_subject_name
  这些在 4.x 里变成返回 const 的可变 getter（CI 的 4.1 上曾报 C2440）

验证（均 -DNETMECH_WARNINGS_AS_ERRORS=ON）：
- Windows MSVC：库对象带 /WX、测试对象不带；构建通过、96/96 用例通过
- Linux gcc：库对象带 -Werror、测试对象不带；构建通过、96/96 用例通过
